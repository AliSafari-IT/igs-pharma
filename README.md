# IGS-Pharma

A healthcare-grade online pharmacy for Belgium, coupled with a pharmacy management platform.

- **Phase 1:** compliant webshop for OTC / non-prescription products
- **Phase 2:** prescription reservations and healthcare workflows

Stack: Next.js (App Router) · TypeScript · PostgreSQL · Drizzle · Better Auth · pnpm/Turborepo — EU-hosted.

📚 **The plan lives in the private docs repo:** [`asafarim-docs/ventures/igs-pharma`](https://github.com/AliSafari-IT/asafarim-docs/tree/main/ventures/igs-pharma) (start at `master-plan.md`): strategy, compliance, architecture, ADRs, design system, roadmap. This repo carries code only.
